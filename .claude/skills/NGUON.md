# Nguồn bộ skill

Các thư mục skill ở đây chép nguyên từ Superpowers 7.0.2 của Jesse Vincent
(https://github.com/obra/superpowers, commit 22f0b46, giấy phép MIT — xem `LICENSE-superpowers`).
Chép vào kho để mọi phiên Claude làm việc trên CamLink (kể cả phiên chạy trên đám mây, ra lệnh từ điện thoại) đều tự nạp.
Cập nhật: chép đè thư mục `skills/` của bản Superpowers mới vào đây, giữ file này và file giấy phép.
